# 设置分类导航选中与悬停

用户已确认方向：细竖线、柔和圆角底色、统一文字留白。沿用五种主题配色，不增加图标或分组。

每行保留原生 Selectable 的点击、键盘焦点和激活行为，绘制区域与点击区域使用同一矩形。行高至少44px，并随字体增大；行间留4px。文字左侧留24px、右侧留12px并垂直居中，选中项加粗。侧栏宽度随最长分类文字增加，避免24px和翻译标签裁切。

选中使用强调色14%混合底色和3px细竖线；悬停为6%混合，按下20%。圆角6px；键盘导航时额外显示细焦点线。各状态均由当前主题颜色计算，不固定为粉色或深色。

实际包验证五主题、18/24px及1120×800/880×600共20种组合：绘制与点击范围、文字留白居中、选择与悬停区分、大小字号不裁切和整行边缘点击，并检查现有Ctrl+K搜索快捷键。程序的Windows入口原本全局关闭方向键焦点切换，本次不启用全局导航，也不将其记为通过；原生Selectable和焦点绘制能力保留。先在旧实际包记录36px行高不符合已确认目标的失败，再用新包复验并给用户真实截图。前端审核通过前不合入QA。

QA整合从最新QA单独提取导航绘制、导航精简及默认外观页，不依赖SettingsPreview，也不包含其他设置功能接线。
