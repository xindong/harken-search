# 高级主题编辑器关系管理

日期：2026-11-20

状态：既有关系仍按会话处理；Wwise 文字独立色随主题保存。

## 行为边界

- 打开内置主题、自定义主题、日夜主题或旧 JSON 时，不会为了建立关系而改写任何颜色。
- 只有关系表中带明确 `sourceKey` 的 `Shared` 字段支持“跟随 / 独立编辑 / 恢复跟随”。
- `Derived`、`Legacy` 和 `SuspectedCoupling` 只显示关系标签，暂不自动传播，避免把公式关系误当成直接复制。
- 旧 JSON 不增加关系元数据；保存仍使用原有扁平 ARGB 字段。

## 会话状态

- 初次打开时，目标值与来源值相同的直接共享关系显示为“跟随”。
- 初次打开时，目标值与来源值不同的关系显示为“独立”，保留旧主题原值。
- 点击“独立编辑”只解除后续传播，不修改当前颜色。
- 点击“恢复跟随”会把来源当前颜色复制到目标，并继续传播到仍跟随的下游字段。
- 编辑来源字段时，只更新仍处于“跟随”的下游字段。

## 撤销与兼容

- 颜色修改、解除关联、恢复跟随、预设切换和导入都进入同一撤销栈。
- 撤销同时恢复颜色草案和关系状态，取消编辑仍回到打开时的完整主题状态。
- 日夜调色板继续使用原有 96 字段编解码，不写入关系状态。

## Wwise 文字

- 在「区域颜色 → Wwise」可以分别独立编辑「标签文字」和「正文文字」。没有独立设置时，两项继续分别读取「菜单文字」和「界面文字」，原有混色、透明度和状态颜色规则不变。
- 「独立编辑」保留当前色值；之后只在 Wwise 面板应用改色。「恢复跟随」移除独立值，重新读取当前来源色。取消或撤销和其他色块一致。
- 旧主题不迁移、不补字段。只有主动设为独立时，导出的自定义主题或保存的日夜调色板才包含对应的可选色值；重新打开仍独立，包括它与来源色恰好相同的情况。
