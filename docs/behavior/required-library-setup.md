# 没有音效库时先完成建库

普通启动未能打开任何音效库时，把原来的上方建库引导面板作为唯一二级窗口显示，压暗其余界面。名称、存放位置和路径预览在打开时直接显示；可以新建、打开已有库或退出软件。背景不再重复显示建库面板。已有数据库即使包含零条音效，也可以直接进入。直接打开音频文件的独立播放入口不触发此流程。

2026-10-29 用户反馈：旧版在背景引导之外又叠加新建弹窗，内容重复；要求沿用原面板、压暗背景，并选择“一打开就显示设置”。本次将内容合为一个窗口，不再新增一步选择。

同日再次按用户框选精简：去掉标题下的引导说明、“存储位置”标题和目录文字。保留选择存放位置按钮、名称输入、完整路径预览、底部提示和操作按钮。

2026-10-29 用户确认 Geist 方向的三个按钮预览：创建、打开数据库、退出统一为平整填色、6 像素圆角，不使用凹陷阴影、高光或渐变。创建为主色实心按钮，打开和退出用较轻的填色及单层细边框；颜色随五主题适配。悬停、按下、键盘导航和禁用行为保留。

同日用户进一步确认普通按钮共用：Wwise、相似音效、设置、库管理、导出、重命名、补链、更新和主题编辑器接入相同绘制层，选择存放位置也随普通按钮统一。输入框、播放器图形、筛选标签和其他自绘图形控件保持原样。设计与模块边界见 `../plans/2026-10-29-shared-button-style.md`。

## 界面与状态

- 触发条件沿用启动状态：需要配置数据库且尚未打开数据库。不能按搜索结果或音效数量判断。
- 复用原面板的标题、配色、主次按钮和细边框，将现有名称、存放位置、完整路径、覆盖确认及错误提示整合其中。窗口放在主界面上方，沿用五主题；长路径换行。
- 强制建库期间，弹窗阻挡主界面操作；取消和 Esc 不能退出流程。可选择“打开数据库”或“退出”。
- 新建或打开在后台进行时保持弹窗，避免重复提交。成功后关闭，失败时保留输入和错误信息以便重试。
- 已有库时主动新建第二个库，沿用原来的取消和 Esc 关闭行为。

## 模块边界

入口与弹窗逻辑位于原生界面；数据库创建、切换、保存和错误处理复用现有实现。数据库格式、扫描、播放、更新和正式用户数据不变。测试读取实际弹窗状态，仅在固定隔离目录的预览编译中可用。
