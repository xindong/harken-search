# 没有音效库时先完成建库

普通启动未能打开任何音效库时，自动进入现有的新建数据库窗口。窗口说明先建立音效库才能开始使用，也允许打开已有库和退出软件。已有数据库即使包含零条音效，也可以直接进入。直接打开音频文件的独立播放入口不触发此流程。

## 界面与状态

- 触发条件沿用启动状态：需要配置数据库且尚未打开数据库。不能按搜索结果或音效数量判断。
- 复用现有名称、存放位置、路径预览、覆盖确认及错误提示，不新建向导或更改五主题风格。
- 强制建库期间，弹窗阻挡主界面操作；取消和 Esc 不能退出流程。可选择“打开数据库”或“退出”。
- 新建或打开在后台进行时保持弹窗，避免重复提交。成功后关闭，失败时保留输入和错误信息以便重试。
- 已有库时主动新建第二个库，沿用原来的取消和 Esc 关闭行为。

## 模块边界

入口与弹窗逻辑位于原生界面；数据库创建、切换、保存和错误处理复用现有实现。数据库格式、扫描、播放、更新和正式用户数据不变。测试读取实际弹窗状态，仅在固定隔离目录的预览编译中可用。

## 验证

使用 tools/qa_required_library_setup.py 在独立 Windows 桌面运行实际 EXE，验证无库启动阻挡、Esc、非法名称纠正、创建空库后放行、重启后空库正常进入、主动新建窗口仍可关闭，以及损坏库打开失败后重新打开有效空库。五主题截图直接取自同一 EXE 实际绘制的画面。

打开已有库的自动测试只替代系统文件选择器返回的路径，随后执行真实弹窗处理与数据库打开。文件选择器自身及退出按钮留给包体验收；自动测试通过实际退出路径正常关闭进程。测试不修改日常资料。用户看到本卡包与截图并明确确认后才记界面验收通过。
