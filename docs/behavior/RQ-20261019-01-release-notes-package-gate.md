# 打包时的更新说明

1. 发布人员为当前版本填写更新日期、说明和贡献者后运行打包，程序将说明文件放入安装包和更新包，用户更新后可以在更新窗口看到该版本内容。
2. 当前版本没有记录，或者日期、说明、贡献者为空时，打包命令返回非零结果；安装包和更新包都不得生成。
3. 贡献者由发布人员根据已确认来源填写；打包程序只校验记录，不自动猜测姓名。

## 公告源的可选英文

`installer/harken_release_history.json` 保持原 schema 版本。英文可写在版本 `headline_en`、分组 `title_en`、平铺条目 `title_en` / `text_en`，或对象条目 `title_en` / `description_en`。

旧分组的 `list` 仍保留原中文字符串。同组可选的 `list_en` 用完整中文原文作为键；新增、删除或移动条目不需要重排译文。修改原文时同步修改译文的键。英文界面只在对应英文非空时采用译文，否则显示原文。旧客户端仍读取原字段。
