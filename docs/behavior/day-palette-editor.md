# 白天独立配色编辑

开启日夜主题后，在白天主题下拉菜单中选择“编辑配色”，进入现有的白天配色编辑器。编辑器可用条件与现有主题编辑功能一致。

保存只写入白天配色，当前处于白天时立即呈现保存后的颜色；黑夜配色和关闭日夜模式时使用的手动主题不变。取消修改或在未保存预览时退出程序，不写入预览颜色。重新启动后继续使用已保存的白天配色。

本次只接回白天菜单的现有编辑路径，不改动其他设置项。

验收脚本拒绝 Python 优化模式，启动前将隔离根目录与实际 EXE 中的编译值核对。测试要求已有且能加载的黑夜配色；18px 和 24px 均验证设置窗口实际为 880×600。预览、保存、取消和两次重启还检查真实捕获帧中主窗口左边缘的目标像素，排除居中的编辑器和色块；关闭设置后等待既有遮罩动画结束再取证。

可重复验收入口为 `tools/qa_day_palette_editor.py`，参数为 `--exe`、`--isolation-root`、`--output`、`--receipt`。回执须包含实际包的 `exePath`、`exeSha256`、`isolationRoot`；启动前核对摘要和路径，并把子进程配置及素材库限制在该隔离根目录内。脚本将测试配置固定为简体中文，在私有桌面通过真实控件验证五种预设、编辑入口、保存、取消、重启、未保存退出、手动主题恢复，以及 18/24px 和较小设置窗口；输出截图、文件摘要与 JSON 结果。精确 RGBA 输入复用已有诊断接口，开关、菜单、保存和取消均走真实控件；预览、保存及重启后的渲染色必须与输入的确切颜色相同。
