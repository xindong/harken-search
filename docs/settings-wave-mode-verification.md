# 设置014：默认显示模式

实际旧包先选择频谱、应用，再选择音量、应用，频谱仍然显示。选择音量或响度只改变了保存的模式，绘制仍取旧的波形样式；仅在原来恰好为RMS样式时，单测响度会偶然通过。先保留该探测，再以跨模式切换的失败记录作为修复依据。

真实下拉选择后，音量同步为实体波形、响度同步为RMS波形，并关闭频谱；频谱启用已有的频谱生成和绘制。继续使用既有草稿、应用、撤销与保存失败回滚机制。响度是波形的RMS呈现，不是新增LUFS检测。用户此前要求去掉的重复波形样式和Mini RMS入口从可见目录及搜索中移除，保留翻译标识和旧设置字段，避免改写已有偏好。

加载旧配置保留已有波形样式；显式重新选择默认模式时才同步相关显示。缺省和越界模式读取为有效范围，实际选择并应用后保存正常值。频谱分区、混合比例和FFT沿用原设置，本卡不调整它们。

可重复入口为 tools/qa_settings_wave_mode.py，指定 --exe、--isolation-root、--output。--red 在旧实际包上复现频谱切回音量失败；默认路径验证草稿、撤销、放弃、保存失败重试、真实重启、双向频谱切换及五主题×18/24px×三种模式。--compat-only 在自己的隔离配置备份上验证缺省和越界模式，正常结束后恢复本卡配置。私有桌面操作不会占用用户鼠标。
