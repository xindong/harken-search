# 外观即时预览

当前头像直接显示在设置页“编辑头像”按钮旁。头像行与编辑工具共用图片预览，保存成功时按版本刷新纹理，同路径替换也立即更新；头像文件和自定义头像标志在保存时落盘。配置保存失败会恢复旧 PNG，首次保存失败不留下新头像；读取临时失败时每秒最多重试一次，文件恢复可读后自动显示，不依赖封面后台任务。验收包含头像PNG、页面实际像素、取消、关闭重开、进程重启和再次替换，以及锁住配置文件的保存回滚、锁住头像后释放的自动恢复。异常回归入口为 `tools/qa_settings_avatar_failures.py --scenario save|read`，使用本卡固定隔离构建和私有桌面。

头像裁剪采用用户确认的固定裁剪框：按住拖动图片定位，滚轮或1至8倍滑杆缩放；重置恢复居中和初始比例。圆形与小尺寸方形预览共用同一个源图区域，保存使用同一裁剪区域输出512px PNG；取消不改头像，保存失败保留图片和裁剪位置供重试。小于8像素的图片还按源图尺寸限制最大放大倍率，避免裁剪为零像素。交互验证使用独立测试目录和私有桌面，不接管用户鼠标。

词库可读性补修：规则触发词和编辑提示使用主题正文色，触发词加粗；已有规则面板使用主题面板色。旧浅色主题实际截图对比度为1.06:1，修复后五主题均不低于9.71:1。实际包检查编辑、取消和关闭，并回归系统字体与列表字体未应用即时预览、撤销恢复；不修改词库内容和保存逻辑。

主题、系统字体、列表字体和列表行高在选择后下一帧就显示在主界面；应用负责保存。撤销或关闭放弃恢复已保存外观。其他业务设置仍是草稿。本次沿用已有界面，不新增控件或逐项审核计划。

当前设置只有本地主题配色，字体草稿尚未进入实际字体重建路径。采用只用于绘制的临时外观覆盖：在字体重建前读取当前草稿，只覆盖改过的外观项；绘制设置和处理应用之前恢复真实设置。下一帧继续从草稿预览。保存函数始终取恢复后的外观值，防止布局自动保存或程序退出把预览写入配置。日夜主题未编辑时继续使用当前实际调度外观。

临时覆盖只管理主题与自定义颜色开关、系统字号、列表字号、行高与密度，分组恢复；不回滚窗口位置、素材库、音量等其他变化。保存失败保持草稿及预览供重试；撤销、放弃或重新打开时基于原有编辑器流程恢复。字体只在 NewFrame 前重建，避免绘制中失效。

验证使用本卡独立素材、私有桌面和实际 EXE。先在旧包上选择24px并确认实际字体仍18px的失败；然后验证未应用即时改变实际字体和全局配色、配置文件仍为原值、行高即时变化、撤销与关闭放弃、保存失败重试和正常重启。覆盖五主题和小窗口。保存本次真实截图、包摘要及源代码身份，用户确认前不合入 QA。
