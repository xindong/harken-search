# CV-7BFE5431 · Mac 工作站程序选择

## 现状与范围

Windows 工作站设置中的“浏览程序”会选择可执行文件，并将返回路径填入当前设置。Mac 当前接到 executable_file_dialog_std.cpp，该实现始终返回空路径，按钮无效。本卡只实现这条 Mac 平台选择路径；工作站发现、桥接安装与音频直送分别验证。

开发基线为 qa/current 的 cfdd64eec1e1115612b3286c4c7591fed5c24c11。为构建和运行真实 Mac 产品，本卡分支需要纳入尚未合入 QA 的 Mac 产品候选 task/CV-2FE9FF37；这只是测试依赖，不代表候选已验收。

## 模块与验证

1. **平台对话框**：在 Mac 主线程打开原生文件选择面板。输入为现有窗口、标题和初始路径。用户选择 .app 时返回包内实际可执行文件的 UTF-8 路径；直接选择可执行文件时返回该文件路径。取消、无效路径、非可执行文件和非主线程返回空路径；不改调用方状态。用隔离生成的应用包及脚本验证解析与拒绝规则。
2. **构建选择**：仅让 Apple 目标编译 Mac 实现；Windows 保持 Win32 实现，其他平台保持原有空实现。构建完整 Intel Mac 产品，并在相同提交上运行 Windows 产品构建和相关回归。
3. **界面与交付**：用隔离设置、素材和数据目录启动本卡应用，核对真实主界面及退出，保留日志、测试包和截图。原生面板的实际点选若未自动化覆盖，单独标记未验证；用户明确确认本包后才进入 QA 整合。

不更改 Windows 设置逻辑、DAW 适配器和音频直送能力判断，也不将本卡测试称为工作站功能验收。
