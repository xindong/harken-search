# Info 标题栏图标与入口显示

## 目标与范围

四页改为标题栏右侧细线图标，移除独立标签行；选中页有下划线，悬停提示完整名称。三点菜单控制显示，保存选择。保留编辑元数据、相似声音、窗口拖动和关闭行为。

主责任域：UI。本次不实现传输历史，不改变音频、数据库、封面查询或历史数据。传输历史仍只在诊断构建可用。图标为本次原创几何路径，无新增图片和依赖。

## 模块设计

### 页面状态

InfoPageNavigation 无界面依赖，保存四位显示掩码和当前页面序号。默认选封面；隐藏当前页切到第一个可见页；拒绝隐藏最后一页；无效设置恢复封面。非诊断构建禁止进入传输历史，但保留该显示位。

### 标题栏与内容

FileInfoPanel 绘制18像素图标，点击区域宽24像素，沿用标题栏高度。主题文字色和强调色用于图标及选中标记。宽度不足时保留当前页与三点按钮，其余可见页通过菜单切换。

四页沿用原内容逻辑，只替换按选中状态分派。封面重建后只切到仍可见的封面，不恢复被隐藏入口。固定、停靠树和浮动窗口共用绘制；拖动区域扣除按钮；浮动图标进入既有标题栏，不占内容行。

### 保存

现有设置读写保存 infoPageVisibleMask 和 infoSelectedPage。旧设置缺失时取默认值；切换及显隐标记 settingsDirty，沿用已有写入路径。

## 验证

- 独立状态测试覆盖切换、隐藏当前页、最后一页限制、恢复、非诊断可用性和无效设置。
- 相关面板和停靠测试、完整 Debug 构建。
- 隔离数据实际运行，验证四页切换、显隐、重启恢复、窄宽度及浮动标题栏点击，提供真实截图。
- 用户确认实际界面后才进入 QA 合并。
