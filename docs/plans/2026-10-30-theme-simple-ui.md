# 日夜主题界面简化

卡片：REQ-20261030-THEME-SIMPLE-UI。原日夜功能卡已经完成，本卡只调整主题设置入口。

## 已确认的结果

2026-10-30 用户看过双状态布局预览后确认“可以就这样吧”，并同意新建后续卡实现。

- 主题区域顶部固定一个“开启日夜切换主题模式”勾选框。
- 未勾选时，直接显示原来的五个主题，隐藏白天、黑夜设置。
- 勾选时，隐藏五个主题，只显示“白天：主题”和“黑夜：主题”两个选择入口。
- 保留两套配色的独立编辑、白天浅色/黑夜暗色、本机 08:00/16:00 自动切换。
- 设计确认只确定布局；修改后的实际包仍需运行、提供真实截图并等待用户验收。

## 模块设计

| 模块 | 最小改动 | 独立验证 |
| --- | --- | --- |
| 设置界面 | 用现有勾选框替换开关；取消日夜大卡和“其他主题”折叠；两组控件互斥绘制。 | 实际点击勾选框，检查两组显示数量、位置和可见范围；截图对照确认预览。 |
| 主题选择 | 每个入口展开现有同类主题和“编辑配色”。白天为柔雾粉/海玻璃；黑夜为经典深色/深海军蓝/极光青。沿用原两份配色文件，选预设只替换对应时段；改色后显示“自定义”。 | 逐一点击五种预设、验证另一份文件内容和时间不变；编辑后读取指定 RGBA、重启核对名字和配色。 |
| 配色识别 | 按已有持久化字段比较颜色，匹配完整内置配色时显示对应主题名，否则显示自定义；不引入额外设置格式。 | 专项测试覆盖保存读回的识别一致性，以及每项颜色修改后不再误认内置主题。 |
| 自动与手动 | 沿用已验收的时间判断、保存、编辑预览保护。取消勾选时固定当前配色，随后选择普通主题进入手动模式；旧固定模式数据继续可读。 | 自动跨时间边界、取消后的时钟跳变与重启、五个手动主题、编辑器直接退出、恢复默认主题。 |
