## 模块边界与验证方法

1. **设置入口与草稿。** 输入是设置面板的波形显示模式选择；输出是草稿、应用后 live 模式及保存的设置键。取消、放弃、保存失败时不能冒充成功。先确认 Mac 上打开设置、选择与应用有可自动化且不占用户鼠标的入口；如需新增诊断输入，只放在隔离 QA 构建，不能进入普通包。
2. **实际绘制。** 输入是独立库的合成 WAV 和三种模式；输出是同一文件、同一窗口内的实体波形、RMS 波形或真实频谱绘制。不能只断言设置值；需核对实际绘制入口、屏幕截图及相关音频状态。旧的主波形缓存与播放逻辑不重写。
3. **保存与重开。** 输入是应用后的设置，输出是本卡隔离目录中的 settings.ini 和下次启动时的同一显示模式。缺省或越界旧设置按 Windows 现有兼容语义检查，不触碰用户日常设置。
4. **回归与交付。** 先记录旧行为或缺少自动验证能力的具体证据，再作最小修改。运行 Mac 产品构建、设置/波形相关测试、真实应用操作和退出；若触及共用代码，取得同提交 Windows 构建及相关回归。包、截图、完整日志和未覆盖项归到 qa/CV-E7493C20/README.md。
