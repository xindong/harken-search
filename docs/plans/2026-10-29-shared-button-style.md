# 普通按钮共用已确认的 Geist 外观

2026-10-29，REQ-20261029-FIRST-LIBRARY。用户确认创建、打开数据库、退出的预览，并要求 Wwise、相似音效、设置、库管理、导出、批量重命名、补链、更新窗口、主题编辑器的普通按钮一起共用。后续选择“保留图形控件”。

## 范围与交付

沿用六像素圆角、平面填色、单层细边框，不画凹陷阴影、渐变或夸张高光。主操作、次操作、安静的取消/退出、危险操作保留区别。五个内置主题使用各自颜色。提供实际测试包和实际窗口截图，等待用户验收后再进入 QA 合入。

播放器图标、工具栏图形、Info 页签、筛选标签、播放列表快捷标签、滑块和波形不变。输入框与整个主题的边框设置不变。

## 模块设计

1. `src/ui/ActionButtonStyle.h` 负责按钮颜色、圆角、边框和临时样式作用域；结束绘制立即恢复上层样式。普通、悬停、按下三个状态共用一种可读文字颜色。加载状态仍使用真正的 ImGui 按钮，禁用点击、保留稳定 ID 和完整标签，转圈图形不另占一个控件或改变下一行的位置。
2. `HarkenSearchWidgets` 提供 `ActionButton(label, size, variant)`，保留现有按钮位置和 ImGui 的自动宽度/铺满宽度规则。既有 `ButtonOptions` 字段顺序和语义不变；Wwise 和相似音效的普通按钮接入同一绘制层，Icon/Ghost 微型图形控件保持原行为。
3. 各窗口只指定文字、尺寸和主次角色，仍拥有自己的业务操作、禁用条件、布局和弹窗。首次建库保留原有真实颜色审计；更新窗口保留原有坐标、标识和诊断区域。主题编辑器取色开关保留选中状态。
