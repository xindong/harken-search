# CV-7AC7255C · Mac 进程发现与路径查询

## 问题与边界

Windows 的编辑器预检会按进程名查找运行中的宿主，并读取所命中进程的程序路径。当前 Mac 的进程枚举返回空列表，系统路径查询和带优先路径查找返回 Unsupported。范围与返回语义以编辑器交接行为说明及现有 Windows 平台接口为准；尚未读取 Windows 原看板卡，不声称已自动同步原卡需求。

基线为 qa/current 的 cfdd64eec1e1115612b3286c4c7591fed5c24c11。真实 Mac 产品构建继续依赖尚未验收的 task/CV-2FE9FF37；该候选及本卡都不因技术测试通过而自动合入 QA。

## 模块与验证

1. **只读进程枚举**：Mac 平台按可执行文件名返回当前可读取的 PID。输入不得含路径或嵌入 NUL，ASCII 大小写不敏感；Windows 目标名的 .exe 后缀可与 Mac 无后缀程序名匹配。枚举不应读取或终止无关进程的内容。用本卡启动的两份同名测试子进程验证匹配、误匹配及退出后消失。
2. **路径与优先匹配**：按 PID 返回 UTF-8 程序路径及可判定的无效参数、未找到和查询失败状态；按名称查询优先返回指定程序路径，找不到优先项时保持现有 Windows 的首个匹配回退语义。用两份位于不同目录的同名子进程验证。
3. **集成与回归**：仅 Apple 产品目标使用新进程枚举实现；Windows 保持原实现，其他平台保持 Unsupported。更新与此接口直接相关的旧静态断言，构建完整 Intel Mac 产品、运行隔离测试和正常启动退出；共用构建或测试改动须在同一提交运行 Windows 产品构建和相关回归。

不修改进程终止、注册表查询、DAW 能力开关或发送路径。进程被发现不等于桥接、IPC 或音频插入可用；真实宿主验证仍另卡处理。
