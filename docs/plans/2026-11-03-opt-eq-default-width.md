# EQ 默认展开宽度设计

- 卡片：OPT-20261103-EQ-DEFAULT-WIDTH
- 目标：新安装或没有保存过 EQ 尺寸时，让底部播放栏的 EQ 控制条以用户截图所示的宽度打开；已有保存值继续优先。
- 设计依据：卡片附件中的实际截图。截图中 EQ 控制条从左侧 EQ 标记到旁通单元约为 520 个界面逻辑像素；这次把 520 定义为命名的默认设计值，不把截图文件尺寸写进布局计算。

## 模块划分

1. **默认值来源**
   - 在 CenterSenseDsp::MagicEQSettings 集中定义默认宽度常量。
   - 非法或缺失的控制线程宽度回退到同一常量，避免首次启动与异常输入出现两套默认值。

2. **播放栏绘制**
   - DrawMagicEQBar 继续使用现有 120–1600 的宽度边界、刻度和拖动区域。
   - 本卡不改 EQ 参数、频段、旁通、拖动算法或其他播放控件；内部刻度会继续按当前宽度规则折叠，窄窗口沿用既有自适应路径。

3. **设置保存与验证**
   - 设置读取仍以 magicEqWidgetWidth 为优先；只有没有保存值时才使用新默认。
   - 保存键、用户拖动后的宽度和其他面板布局保持原样。

## 验证清单

- 先用源代码契约测试证明当前 180 默认值会失败，再改为 520 后通过。
- 运行现有 Magic EQ UI 契约测试。
- 构建本卡实际包并检查新用户默认、已有保存宽度和窄窗口下的绘制边界。
- 留存实际包与真实截图；界面验收需用户确认后才能收尾。

## 不在本卡范围

EQ 音频参数、频段范围、旁通逻辑、拖动交互、播放控制、波形、主题和其他面板尺寸。
