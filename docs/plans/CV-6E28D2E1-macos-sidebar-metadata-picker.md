# CV-6E28D2E1 · Mac 侧栏元数据长列表筛选实机验证

## 来源与基线

- 来源：Windows QA PR #83 和仓库当前侧栏筛选行为；2026-11-04 读取 origin/qa/current 6573402de540c3d489b5a293d0cd7b6c45808be5。该分支已包含 Windows 的艺术家、专辑、分类长列表弹层。Mac 独立卡先从此提交建立，再合入尚待用户验收的累计 Mac 候选 1b4dc0d3297abf414ab7af5d596adc6fba0ddd9d。
- 本卡只检查 Mac 上真实应用的元数据筛选交互。输入是隔离素材库中多于 20 个不同艺术家、专辑和分类的合成音频记录；输出是弹层、应用中的三个筛选值及实际搜索结果。不能把 Windows 的通过记录当作 Mac 验证。
- 用户已要求 Windows 与 Mac 共用核心功能，修改一个筛选值不能清空其他筛选条件。界面外观沿用已进入 QA 的方案，本卡不重新设计。

## 模块、失败处理与独立验证

1. **名单和输入。** 核对三个字段点击输入框或箭头都能展开完整名单，长列表可滚动、输入包含匹配、点选才应用筛选。测试空结果、长名称和再次展开的新值；未选择时点空白关闭，保留已应用值。先记录真实应用旧行为，若有缺口只修已复现问题。
2. **组合筛选。** 在独立库逐项选择艺术家、专辑、分类，再更改其中一项，检查另两项仍保留且实际结果数符合数据。检查“全部”仅清除当前字段；不改共享查询算法或日常素材库。
3. **隔离实测。** Mac 诊断输入只能在隔离 QA 构建启用，不占用系统鼠标。保留每项原始状态、实际窗口截图、正常退出与重开记录。若现有诊断通道缺少可观测状态，先写会失败的运行检查，再补最窄的 QA 观测与输入；普通产品包不得启用诊断命令。
4. **回归交付。** 运行相关 C++/Python 行为测试、Mac 实际包和退出；若触及 Windows 共用代码，取得同一提交的 Windows 构建及相关回归日志。测试包、截图、差异与完整错误日志集中在 qa/CV-6E28D2E1/README.md。用户未明确验收前保持卡片 in_progress，不合入 QA 或 main。
