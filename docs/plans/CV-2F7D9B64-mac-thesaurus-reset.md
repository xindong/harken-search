## 范围和行为

- 主模块：设置中的词库页面。输入是平台返回的实际 activePath；页面显示这一保存位置，打开 JSON 仍指向同一文件。恢复默认后重新加载内置规则，重开应用时规则也保持默认。
- 次要边界：Mac 用户设置目录。仅操作本应用当前的规范词库文件；Windows 继续按原程序目录处理新旧词库及迁移标记。无效或只读路径不得声称重置成功，也不能误删包内文件。测试只用本卡隔离数据。
