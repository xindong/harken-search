# 更新过程界面设计与验证

日期：2026-10-29。

## 目标与范围

点击更新后持续展示真实的检查、退出、替换和启动状态；主程序关闭后仍有反馈。正常界面只保留官方 Logo、目标版本、当前状态和进度，成功后自动关闭，失败时保留原因、错误码和关闭按钮。

不在已经运行的更新中再次显示“立即更新”“稍后”或详情面板。不新增历史安装删除功能，不强制结束用户进程，不修改签名和安装身份校验，不将计时动画当作实际安装进度。

## 过程与显示模块

- 核心通过 BootstrapProgress 观察接口发布拥有自身数据的快照；界面不能反向发起文件替换、重试安装或结束进程。
- 版本来自已验证的安装计划。替换数量只在文件写入且对应日志写入成功后增加；无法量化的等待阶段使用循环动画。
- 运行核心的 Completed/Failed 观察消息不提前结束窗口，最终状态以入口 Finish 结果为准。终态不可被迟到快照覆盖。

## 独立窗口与网页模块

- 独立更新器拥有自己的 Windows 窗口及 STA 线程，HTML/CSS/脚本和官方 PNG 由构建内置，替换安装文件时仍可显示。
- WebView2 Loader 静态链接，不引入更新目录中可被锁定的 Loader DLL。异步回调使用可失效弱引用，关闭时解除回调并释放控制器。
- 启动浏览器前清除更新交接与父进程句柄的继承标志；启动代理能力也先转为不可继承句柄。终态清理进程另行取得明确的继承句柄。
- 页面只接受状态数据，只允许发送 ready 与终态 close 消息；CSP 阻止外部资源和表单，权限请求被拒绝。
- WebView2 不可用时显示原生状态窗口；成功关闭有绝对截止时间，页面初始化失败不会阻止更新交接。
- 浏览器缓存仅写入当前用户的更新界面缓存目录，不读取素材库或修改安装权限。

## 失败语义

- 错误 21 表示旧程序未在期限内退出，此时尚未替换文件。
- 错误 50 表示文件已替换但未确认新版本就绪，不能显示“当前版本未改动”。
- 失败后停止进度动画并保留简短处理说明。页面本身不提供未获核心支持的重试或取消。

## 设计来源

参考 21st.dev 的 Staged Progress Bar、Waveform Loader 与 Origin UI Stepper 的公开交互原则，自行实现页面，不复制登录后组件源码。官方标识使用产品已有原始 PNG，不重绘。

- https://21st.dev/@su2491251/components/waveform-loader
- https://21st.dev/@originui/components/stepper

## 可重复验证

- 进度视图、窗口生命周期及真实 WebView2 状态分别有原生测试，覆盖未知进度、文件数量、终态不可逆、延迟加载、关闭计时器失效和原生后备提示。
- 真实隔离事务使用独立桌面及测试签名包，执行旧进程退出、64 个文件替换、新进程健康回执、临时更新器清理和事务日志退役。另覆盖退出超时和启动失败。
- 测试入口完整性检查拒绝不存在的测试文件、模块和发现目录。修正目录改名后的重复根测试样本，恢复仍服务产品的检查资料，移除已淘汰私人流程的失效注册。
- 平台审计按固定路径及完整调用指纹约束新 Windows 适配代码，不作整目录放行；行号移动本身不改变已审核边界。

## 已验证范围与限制

2026-10-31 合入当前 QA 后复验：完整根工程 512 个 CTest 项目通过；独立更新器 12 个项目通过，其中黑盒项目补齐隔离测试环境的 PyNaCl 后单独复验通过。原有两项可选 DPI 可执行文件/运行时探针未启用，不计作执行通过。

本轮修正 8 项失败：按钮与首次建库检查对齐已验收界面；刷新、文件夹与封面检查保留其他筛选条件；主题文件读写及统计线程编号使用公共平台层；文件关闭错误继续向上传递；主题选项使用独立标识；新增公开接口关联现有测试证据。保存失败覆盖原文件保留与临时文件清理。

未修改的官方 1.0.40 在全新 Windows Sandbox 中从 COS 升级到官方 1.0.41，已验证旧进程退出、新版本与摘要一致、同发布者有效签名、测试数据保留及事务文件清理。该历史测试不含本次新界面。

本卡正式签名整链另外使用当前代码、仅将版本身份设为 1.0.40 的隔离测试源。主程序与本卡更新器均由既有公司签名服务签署，签后刷新配对记录，并与 COS 正式目标核对签名证书。保留源提交、版本身份补丁、构建参数、签名后摘要和实际升级记录；不能将测试源称为历史公开 1.0.40，也不发布或改写线上更新清单。最终结果以本卡验收证据为准。

未签名 QA 源与公司签名目标混用的尝试发生终态交接失败，不计作成功，也没有放宽签名检查。原生产退出超时 21 尚未复现，不能宣称已修复。测试包、截图、失败现场和详细运行记录仅在本机留存，前端人工验收按任务记录办理。
