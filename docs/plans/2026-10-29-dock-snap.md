# Dock 边缘吸附修正

## 目标与原因

拖动浮窗经过文件列表中间时保持悬浮；靠近目标边缘才出现停靠预览。当前鼠标命中使用的是一点，但文件列表中央的大面积回停区域会把这一点映射到窗口记忆的停靠方向，导致远离右边的 Info 也提示右侧停靠。

2026-10-29 用户补充：文件列表的上下也支持 Dock，方便竖屏。沿用本卡，新增列表上沿和下沿停靠；列表中间仍不吸附。上下停靠仅占中央这一列，菜单、两边侧栏和波形不作为新增停靠区。

## 模块设计

- `DockHitTest.h`：文件列表回停目标使用上、下和记忆方向的内侧边缘带，沿用现有最大 48 像素距离。已有 Dock 面板四边的分栏优先级保持不变。已有根区域不被文件列表回停逻辑覆盖。空根命中也保留窗口记忆的宽度或高度。
- `main.cpp`：传递真实文件列表边界，移除中央内缩大矩形；继续使用鼠标位置而非浮窗外框判断。预览与松手沿用同一个命中和可读尺寸计算。
- `DockDragSession`：不改状态机。用测试确认离开边缘后清空预览、松手保持悬浮，Esc 仍恢复原布局。
- 上下停靠：命中列表上/下边缘，不依赖窗口原来停在左右哪边。候选窗口使用自身记忆高度，底部位置以波形上方的内容边界为准；至少给文件列表留 200 像素高度，放不下时不接受停靠。
- 中央布局：上下带的宽度随左右侧栏剩余宽度计算，侧栏维持完整内容高度。预览和实际放下使用同一上下区域；各可停靠面板的高度可调整并保存。上下分隔线各独占 6 像素间隙，避免列表子窗口遮住拖动区域，停靠尺寸计算同步扣除间隙。

不改变主题、窗口尺寸规则、持久化格式或其他面板内容。此次没有新的视觉资产，沿用现有真实停靠预览，无需 Figma。

## 步骤与验收

1. 增加中央不吸附、四个方向边缘可回停、离开边缘、记忆宽度与取消拖动的回归用例；先观察旧实现失败。
2. 最小修改命中范围，运行 Dock 命中、布局、拖动和原生标题栏相关检查。
3. 构建独立测试包，通过程序自己的隔离输入接口执行真实拖动，保存中央无预览、边缘有预览、离开后松手保持悬浮的截图及操作记录。
4. 交付能打开素材库副本的入口，等待用户确认本版体验。确认前不记验收通过、不合入共享 QA。

## 进度

- 已定位中央隐藏回停区。
- 第一阶段中央误吸附修正已通过 4 项 Dock 程序测试、23 项 Python 接线检查，以及真实包的 7 个状态截图；尚未经用户确认。
- 上下停靠用例先观察旧逻辑失败，修正后 4 项 Dock 程序测试、23 项 Python 接线检查通过。
- 实际包验证横屏和竖屏的上下停靠、预览与最终位置一致、侧栏保持高度、至少保留 200 像素列表、上下同时停靠、调整高度和重启恢复，共 18 个实际状态通过。
- 实机检查发现分隔线曾被列表覆盖，先观察到拖动后高度不变，再为分隔线保留独立间隙，复验调整高度及重启保留均通过。
- 原生窗口截图在本机出现全黑后，使用只在本机测试包临时加入的 OpenGL 画面读取取得实际渲染截图；代码及像素处理没有模拟界面。该临时补丁和验收说明面板均已从产品源码撤回。
- 最终测试包与截图已生成，等待用户确认本版体验，尚未合入共享 QA。
- 用户随后授权先合入 QA/main、从 main 打包但暂不发布；又要求优先修 Info 右边框并先看预览，因此远端合并继续暂停。
- 上下停靠的 Info 原先直接绘制内容，封面区域延伸到右边框；现沿用右侧栏的受限内容容器和留白。已用新包复验 18 个 Dock 状态、停靠时的内容边界及 5 个主题截图；预览先交用户查看，尚未提交合并或发布。

## 发布前回归

- 2026-10-29 用户确认实际 Info 边框预览，并要求重测当天转仓功能，通过后发布最新包。发布范围为已合入 QA 的桌面功能及本卡修正，版本递增为 1.0.41。
- 正常构建下 283 个程序测试全部通过，公开仓检查 238 项通过、2 项按既有条件跳过；发布工具 89 项通过。宽范围脚本回归发现旧仓专属资料引用，按既有公开仓迁移清单单独记录不适用范围，不恢复旧治理或官网目录。
- 回归修正 Info 窄面板菜单标识、未保存提醒的滚动条接线，以及网络只读素材库错误被普通保存失败提示覆盖的问题；失败仍保留草稿。同步已迁入模块的测试清单、当前函数签名和主题基准，保留实际行为断言。
- 正式合入与发布仍须以最终源码、隔离包交互复验、远端检查、签名安装包和公共下载验证结果为准。验收说明及读取画面的临时补丁不进入共享分支。
- 远端复核指出极窄中央列的预览可能加宽，以及恢复/缩小窗口时上下区域可能挤出底部。两项新用例先在旧实现失败；修正后上下预览严格使用中央列宽，窄于模块下限时拒绝停靠。已有上下区域先缩减记忆高度，仍放不下时从下方开始恢复悬浮，给文件列表和底部留出空间；再次打开保留悬浮状态。
