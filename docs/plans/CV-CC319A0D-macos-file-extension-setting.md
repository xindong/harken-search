- 目标：在 Mac 真实设置窗口点选“显示文件名后缀”，检查设置草稿、应用与磁盘保存，以及实际结果列表的原始文件名和绘制文字。测试输入使用本卡隔离目录生成的多点号、大写后缀和中文 WAV，以及本机可实际转换的音频格式；不复制用户素材。格式未生成时如实标记未覆盖。
- 不调整现有设置界面，不改 Windows 控件、搜索算法或音频文件名。若界面外观须变化，先给预览并等待确认。

## 模块边界与逐项验证

1. **设置草稿。** 在真实设置面板点开该开关；读取草稿、当前值、待应用项与磁盘键。撤销和关闭放弃不能改变已保存值；注入一次隔离保存失败，检查错误提示与回滚，然后重试保存。
2. **列表绘制。** 使用已有主列表绘制处的隔离诊断记录，核对有后缀时原名与显示名相同、隐藏时只去最后一个后缀。多点号、中文、大写后缀分别检查；索引和搜索结果顺序不能因显示选项改变。若现有 Mac 测试桥缺少可观测字段，先保留失败记录，再补只限隔离 QA 的观测。
3. **文件与重开。** 保存前后比较合成文件的路径和 SHA-256，避免仅为显示而重命名或改写文件；正常退出重开仍保持设置和库。实际包截图、逐条状态、原始错误、定向测试和完整日志放在 qa/CV-CC319A0D/README.md。
4. **Windows 影响。** 本卡若只增加 Mac 隔离测试入口，共用设置逻辑不修改；仍核实最终分支与最新 QA 关系，并以同提交 Windows CI 确认产品构建及相关回归。用户未明确验收前不合入 QA 或 main。
