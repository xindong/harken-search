# 扫描入库界面精简

## 确认范围

2026-11-01，用户确认第三版预览：“这样可以 开始吧”。本轮实现扫描入口、阶段进度、暂停与撤销、独立结果、异常提示及可选相似分析。设计确认不等于实际测试包验收。

只改变呈现与必要的结果记录，不修改扫描算法、数据库结构、回滚语义、系统标题栏、其他窗口的外观。已有设置值保留；新扫描默认包含子文件夹、更新已有文件、自动线程，移除失效记录与相似分析默认关闭，模式沿用已有配置。

## 模块与实现

| 模块 | 现有入口 | 本轮结果 |
| --- | --- | --- |
| 窗口外壳 | main.cpp 扫描弹窗 | 同底色标题、无顶部横条、无底框关闭 X，沿用主题与普通按钮组件 |
| 扫描入口 | showScanDialog / pendingScanFolders | 摘要、可展开目录、高级选项和开始操作；去掉调试信息与重复解释 |
| 扫描进度 | ScanWorkflowSnapshot | 阶段、单组真实数量、进度和当前文件；统计/收尾不显示伪百分比 |
| 停止选择 | requestPauseScanTask / requestCancelScanTask | 暂停保留、撤销本次入库、继续扫描；保存/撤销中不重复提供操作 |
| 扫描结果 | 完成快照及错误副本 | 与设置、进度分开；成功数量、展开统计、分类失败与完整详情 |
| 异常/拖入 | WindowsMain.cpp 拖拽分支 | 只在发生时显示简短结果或不可访问原因，不展示原始英文诊断 |
| 相似准备 | StartBatchFeatureExtraction | 扫描后可选进度、后台入口、停止/结束结果；处理数与成功数分开 |

展示状态从已有快照生成纯同步值，不访问数据库、不等待工作线程。共享控件只局部使用，不修改全局标题栏或按钮风格。失败详情继续保留实际错误；未能分类或被截断的错误不能伪造原因。

## 行为与验收

- 打开入口只见目录摘要、当前模式、高级选项和开始/取消；展开后原选项都可用。
- 计数阶段和收尾阶段无伪百分比；波形阶段用波形数量而非已经100%的文件入库数量。
- 暂停保留与撤销仍调用原接口；继续/关闭停止选择回到原阶段，不触发停止。
- 完成、部分失败、暂停、撤销、空结果和失败不会与扫描选项混排；错误不计入成功。
- 结果关闭不启动新扫描；再次扫描仅重新确认原目录，不擅自换目录。
- 五主题与窄窗口中标题、长路径、按钮无裁切；X 的普通/悬停/按下无底框。
- 用本卡实际包和隔离目录执行扫描、暂停、撤销与相似分析，保存真实截图；人工确认外观后才进入合入流程。

## 2026-11-01 验收反馈：保留速度和总用时

用户原话：“可惜你把速度和总用时去掉了”。补回进度区紧凑一行的真实速度与累计用时，结果页直接展示固定用时，不藏在统计中。速度取当前阶段处理量的实际变化，阶段切换和新任务不沿用旧速度；统计、保存和整理等没有可测处理量的阶段显示待测，不假造零速。用时跨阶段累计，暂停、撤销或完成后固定；窄窗口可换行，其他已确认布局保持不变。

本轮仅修改展示采样与必要测试，不改变扫描、数据库和停止处理。先让遗漏速度/用时的回归检查失败，再用新版实际包检查正常扫描、阶段切换、暂停与完成，留存同包截图和验收入口。旧包保留，不直接覆盖，也不合入或发布。
