# 将 Harken Search 项目规则与常用方法收进仓库

卡片：TASK-20261029-LOCAL-RULES

## 本次目标

把 Harken Search 开发时真正需要的规则和常用方法整理成仓库内可直接阅读的入口，避免以后依赖其他仓库的本机路径或旧文档。

## 模块划分

### 1. 项目入口：docs/agent-methods/project-rules.md

说明沟通方式、最小范围、独立 clone、Cuevi 记录、中文文件编码、测试边界、界面验收和收尾规则。本机 AGENTS.md 保持不跟踪；机器路径和凭据只由本机入口提供。

### 2. 通用方法：docs/agent-methods/

分别整理系统排查、TDD、完成前验证、界面验收和 Cuevi 简化工作流。每份文档只负责一个主题，便于单独阅读和修改。

### 3. 文档契约测试：tests/test_local_agent_docs.py

检查入口文件和方法文档存在、能按 UTF-8 读取、没有旧外部仓库路径，并检查入口中的相对链接仍然有效。

## 不做的事

- 不把旧仓库的整套历史资料或岗位流程复制进来。
- 不修改产品代码、数据库结构、界面和现有测试逻辑。
- 不把外部仓库的绝对路径写进本项目入口。

## 验收方法

运行 tests/test_local_agent_docs.py，确认 3 项文档契约通过；再检查 Git 差异和全文编码，确保新增内容只在本卡独立 clone 中。协作方法及其契约测试属于开发资料，不混入面向产品用户的公开导出集合。
