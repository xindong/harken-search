# 文件夹筛选与关键词搜索互相重置

卡号：BUG-20261029-FOLDER-SEARCH-RESET。基线：qa/current e60564035e72861be25dd9c9050ac5786df5ca53。

## 已确认范围

主界面数据库视图中，关键词搜索保留左侧选中的文件夹；换文件夹保留搜索词。相同文件夹与关键词，两种操作顺序得到相同结果。只改这两种条件的联动，保留“显示全部”、单独清空条件和封面筛选现有用途。不涉及扫描、播放或数据库结构。

## 模块设计

1. 交互状态：回车搜索和实时搜索共用的提交入口只更新关键词，不撤销文件夹筛选；文件夹树点击延迟生效时只更新文件夹范围，不写搜索词。保留封面点击筛选在新搜索时清除的原逻辑。此模块通过两种搜索入口和文件夹切换的状态检查验证。
2. 查询组合：沿用 BuildCurrentDbFilter，从同一状态读取关键词与文件夹路径并交给现有查询。此模块用不同操作顺序的相同条件测试，以及实际素材库结果核对；不改数据库查询实现。
3. 交付验收：完整编译 VS2022 x64 Debug HarkenSearch，从本卡分支打隔离 QA 包，实际打开素材库；记录两种顺序、换词、换文件夹和清空条件的结果及真实截图。用户确认本版界面后才能登记前端通过。

## 当前进度

已定位搜索提交入口主动清除文件夹筛选；换文件夹的延迟提交入口本身不写搜索词。失败测试先证明前者存在，最小修复后通过。完整 VS2022 x64 Debug 程序已编译。原测试命令会直接刷新查询而绕过故障入口，已改成隔离 QA 专用 lane：实时模式让 RenderUI 自己处理防抖；回车模式把 Enter 注入原生 ImGui；文件夹选择通过 pendingFolderPath 进入同一个延迟处理分支。自动操作不占桌面鼠标。
