# 默认字号调整详细设计

卡片：OPT-20261103-DEFAULT-FONT-SIZES。基线：本卡从 origin/qa/current 的 a4e733446e20978ccf6c91f67ef2a73c090acb8a 建立。

## 目标与范围

设置页的「系统字体大小」对应 readingFontSize，作为系统阅读区域和弹窗正文的字号；「列表字体大小」对应 listFontSize，供音效文件列表的数据行使用。未保存过字号时，两项分别取 16 和 18。已有配置中的 readingFontSize、listFontSize 继续优先；旧版 listFontSize、fontSize 对阅读字号的兼容顺序不变。设置页现有字号档位和调节操作不变。

固定的控件字体 kChromeFontPx 是另一组字体，不属于这两个设置项；本卡不改其数值、布局、行高、列宽、筛选、播放、主题、其他文案或字体缩放逻辑。播放列表是否另用文件列表字体，以现有调用位置为准，不增加新的设置项。

## 模块一：设置默认值与旧配置读取

- AppSettings 的 readingFontSize 默认为 16，listFontSize 默认为 18。两项独立，不能因阅读字号已有保存值就让未保存的列表字号跟随它。
- 读取设置文件时，显式保存的 readingFontSize 优先；旧 listFontSize、fontSize 继续按现有次序兼容阅读字号。两项都不存在时阅读字号取 16。
- 显式保存的 listFontSize 继续优先并保留 10–24 范围限制；没有该键时列表字号取 18。保存键名保持不变，不做迁移或清除。
- 单独验证新用户、仅保存阅读字号、仅保存列表字号、两项都保存及旧键读取，确认各自优先级。

## 模块二：运行时和恢复默认大小

- 字体加载仍按 readingFontSize 和 listFontSize 两组分别构建；设置页现有两项选择继续写回各自字段。
- 「恢复默认大小」同时恢复为 16 与 18，固定控件字号保持既有值。整组重置使用 AppSettings 默认值，不另设特例。
- 用实际包和隔离设置核对系统阅读区域、文件列表、已保存设置及手动调节；提供同一实际包的真实截图等待用户确认。

## 执行与交付
