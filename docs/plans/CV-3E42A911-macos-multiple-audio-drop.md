## 来源和边界

2026-11-05 读取正式 Mac 看板，无同题卡或其他活跃负责人。最新 origin/qa/current 为 22fcaed3f4f8d95fd64c4153d52ddb38b51de7c4。Windows 当前 WM_DROPFILES 能分类并逐个处理最多 200 个直接音频文件；原 Windows Cuevi 卡未在本机读到，不宣称需求实时同步。Mac 上一张 CV-9C62F17A 候选 3ae2c60 已有单文件拖入与共享入库修复，但尚待用户验收、未合 QA。先把它作为显式开发依赖并入本卡独立分支，记录合并冲突与最终 SHA；不把它误报为已正式整合。

## 模块、输入输出及失败处理

1. Cocoa 拖入判定：单个或小批量纯音频文件 URL 可接受，最多 200 个；保留单个 .db 与文件夹原有路径。混合文件夹、数据库、非音频、无库、扫描中及超过 200 个音频拒绝，不能触碰库。重复 URL 只处理一次；不存在或无效路径不能伪装成功。大批量改用确认扫描属于后续卡。
2. 批量入库：复用共享 Database 的显式手动导入方法，每个文件各自记录新入库、已有或失败；坏音频不写入。完成后只刷新一次搜索，复用已有提示栏显示计数；试听首个实际成功的文件，失败的首项不能抢占播放。即使中间一个文件失败，其他有效文件继续。源文件不改。
3. 验证：先在合入最新 QA 与上卡候选的真实 Mac 入口复现多文件被拒；修改后用本卡独立库和合成 WAV 做成功、重复、坏文件、混合输入及扫描中拒绝，核对 SQLite、标题计数、试听/波形、正常退出重开和源文件哈希。重跑单文件、文件夹与数据库拖入回归，构建内部隔离包并用解压包实际运行、截图。
4. 跨平台：本卡产品改动仅限 Mac 拖入入口；合并候选包含共享数据库和最新 Windows QA，最终提交仍需同 SHA Windows 产品构建与相关回归。未做 Windows 桌面鼠标实操，原有卡仍待用户验收。
