# 全软件现有窗口关闭 X 统一设计

卡片：REQ-20261029-UNIFIED-CLOSE-X。基准：用户已确认的「关于」窗口右上角共用 Lucide X 图标按钮。

## 范围与验收

- 只处理现有的窗口关闭 X：关于/法律文档、相似音效独立窗口、检查更新窗口、Windows 主窗口标题栏，以及启用多视口时的系统标题栏。
- 原本只有“关闭”文字的弹窗不新增 X；筛选标签、规则行等删除用途的 × 不变。
- 各窗口仍走原有关闭路径。主窗口仍按“询问/最小化到托盘/退出”设置处理。
- 实际软件显示同款细线 X 和轻量悬停底色；保留拖动、标题栏双击最大化、边缘缩放、最小化、最大化与系统快捷键。

## 模块 1：应用内 X

检查更新窗口在原坐标使用共用图标按钮，保持诊断点击区域登记与原关闭状态收尾。相似音效独立窗口保留标题栏原点击区域，只将手绘 X 和悬停底色改为共用图标按钮的字形、颜色和圆角底色。ImGui 自带标题栏的关闭 X 使用相同细线几何，避免其标题栏字体缺少 Lucide 字形而出现缺字标记；标签页删除 X 不变。五主题的关闭图形按实际底色保证至少 3:1 对比度。关于/法律文档已由原卡使用共用按钮，此卡不重复修改。

## 模块 2：Windows 系统标题栏 X

Windows 原生标题栏没有单独替换关闭字形的公开属性。为使用同款 X，窗口需自行绘制非客户区标题栏，同时维持系统窗口语义。Windows 平台模块负责计算标题栏与按钮区域、按 DPI 绘制细线 X、处理命中和悬停；关闭按钮进入原 WM_CLOSE 路径。最小化、最大化及其区域保持可用。启动画面的无框样式不绘制标题栏。主窗口与附加视口共用此模块，附加视口继续走现有停靠事件分发。

重点核对：普通与最大化时的位置、缩放和标题栏双击；Alt+F4；主窗口三种关闭设置；独立视口关闭时不退出主程序。不能仅凭图形相似判定完成。

## 模块 3：验证与交付

先让独立布局测试覆盖不同宽度、DPI 与按钮命中边界并观察失败，再实现并跑聚焦测试。构建本卡隔离包，用独立设置与素材库运行，截取主窗口、关于、检查更新和相似音效的真实界面。记录包、源码版本与截图，交用户确认后才记前端验收。此卡与关于卡按通过时间排队合入 QA。

参考：https://learn.microsoft.com/en-us/windows/win32/dwm/customframe

## 已实现的细节与验证

- Windows 平台模块用纯计算部分确定关闭、最大化、最小化和拖动区域。系统标题栏保留原有窗口操作，绘制 12px 的细线 X 和 26px 的轻量圆角悬停底色；标题栏高度、按钮宽度及图形均按窗口 DPI 缩放。关闭动作仍发送到窗口原有的 WM_CLOSE 路径。禁用 Windows 默认非客户区着色，避免深色主题顶部出现浅色条。
- 应用内的 X 复用图标按钮。相似音效独立窗口保留原有点击区域，只替换绘制；检查更新窗口保留原有关闭逻辑与诊断点击区域；可分离模块的标题栏 X 改成相同细线几何，标签页删除 X 不受影响。
- 用独立的窗口布局测试和原生窗口点击测试核对按钮命中、关闭及缩放；用本卡独立数据目录打开 1408 个文件的素材库，核对五套主题的主窗口、检查更新、相似音效和分离模块。桌面截图只短暂置顶本卡窗口，不移动或占用用户鼠标，也不激活其他窗口。
- 关于／法律文档页面的 X 由已验收的前置卡 REQ-20261029-ABOUT-LEGAL-CREDITS 提供。交付包会纳入该卡源代码，以便用户一次看完整效果；两张卡依旧按各自验收时间排队进入 QA。
