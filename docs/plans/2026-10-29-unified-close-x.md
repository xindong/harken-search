# 应用内现有窗口关闭 X 统一设计

卡片：REQ-20261029-UNIFIED-CLOSE-X。基准：用户已确认的「关于」窗口右上角共用 Lucide X 图标按钮。

## 范围与验收

- 只处理应用自己绘制的现有窗口关闭 X：关于/法律文档、相似音效独立窗口、检查更新窗口，以及可分离模块的 ImGui 标题栏。
- 原本只有“关闭”文字的弹窗不新增 X；筛选标签、规则行等删除用途的 × 不变。
- Windows 系统标题栏及其整圈系统边框恢复原样；其 X、最小化、最大化、拖动、缩放及系统快捷键都由 Windows 原有机制处理。
- 应用内窗口仍走各自原有关闭路径，显示同款细线 X 和轻量悬停底色。

## 模块 1：应用内 X

检查更新窗口使用共用图标按钮，局部将 X 放大到与「关于」页一致的 12×12 像素，并与「更新历史」按钮垂直对齐；保持诊断点击区域登记与原关闭状态收尾。相似音效独立窗口保留标题栏原点击区域，只将手绘 X 和悬停底色改为共用图标按钮的字形、颜色和圆角底色。ImGui 自带标题栏的关闭 X 使用相同细线几何，避免其标题栏字体缺少 Lucide 字形而出现缺字标记；标签页删除 X 不变。五主题的关闭图形按实际底色保证至少 3:1 对比度。关于/法律文档已由原卡使用共用按钮，此卡不重复修改。

## 模块 2：可分离模块的应用内标题栏 X

只在 ImGui 原本绘制的窗口关闭按钮上启用同款细线 X。可分离模块继续走原有关闭事件；标签页上用于删页的 X 保持原样。窗口外层的 Windows 系统标题栏和边框不再改动。

重点核对：可分离模块的应用内 X 可见、没有缺字标记，Windows 标题栏和整圈边框与改动前一致。

## 模块 3：验证与交付

构建本卡隔离包，用独立设置与 1408 个文件的素材库运行，截取主窗口、关于、法律文档、检查更新、相似音效和可分离模块的真实界面。核对五套主题和检查更新 X 的关闭动作；记录包、源码版本与截图，交用户确认后才记前端验收。此卡与关于卡按通过时间排队合入 QA。

## 已实现的细节与验证

- 2026-10-29 用户纠正：原话「谁让你改标题栏的，那个不用改回退 到之前的总边框」。已撤回对 Windows 系统标题栏与系统边框的改绘，包括原生绘制模块、调用和测试。
- 应用内的 X 复用图标按钮。相似音效独立窗口保留原有点击区域，只替换绘制；检查更新窗口保留原有关闭逻辑与诊断点击区域；可分离模块的标题栏 X 改成相同细线几何，标签页删除 X 不受影响。
- 用本卡独立数据目录打开 1408 个文件的素材库，核对五套主题的主窗口、检查更新、相似音效和分离模块。桌面截图只短暂置顶本卡窗口，不移动或占用用户鼠标，也不激活其他窗口。
- 关于／法律文档页面的 X 由已验收的前置卡 REQ-20261029-ABOUT-LEGAL-CREDITS 提供。交付包会纳入该卡源代码，以便用户一次看完整效果；两张卡依旧按各自验收时间排队进入 QA。
- 2026-10-29 用户指出「检查更新的x还是有问题」。实际截图测得原 X 仅 8×8 像素、视觉中心比右侧「更新历史」按钮高 6.5 像素；原因是「关于」页使用 1.55 倍窗口字号而「检查更新」未跟随。先新增从真实截图量取字形及对齐的检查，旧包按预期失败；局部调整字号和纵向位置后，新包 X 为 12×12 像素、与按钮中心相差 0.5 像素。五主题实际截图和点击关闭检查通过，Windows 系统标题栏原样保留。

## 合并前复核跟进（2026-10-31）

用户已明确确认统一验收入口中的本卡交付。随后合并前复核发现：关闭 X 仅按普通背景选色，海军蓝悬停态和另一深色主题按下态不足 3:1；旧截图检测还会把整块浅色或海军蓝背景误认成字形。保留原验收及失败记录，不将自动检查冒充新状态的人工确认。

- 最小修改仅覆盖共用图标按钮中的关闭 X：保留原按钮 ID、大小、布局、输入和背景，在当前帧状态确定后按实际合成底色绘制同一字形。普通、悬停和按下均检查量化后的 3:1 对比度，其他图标与 Windows 原生标题栏不改。
- 截图检测改为从按钮内部实际背景提取差异笔画，并排除边框和大片背景；空白、微小字形以及浅色/深色字形均须有可重复测试。
- 新增真实 ImGui 输入及绘制颜色回归和截图检测回归，纳入线上检查；重新构建隔离包，补充受影响状态的实际截图与关闭操作，再提交验收。

## 无底框与对齐补修（BUG-20261031-CLOSE-X-CENTER）

2026-10-31 用户指出高亮框尺寸不对，随后决定取消框。关于与检查更新共用的关闭图标按钮改为只绘制 X：普通、悬停和按下不再绘制底色或边框；悬停、按下及键盘焦点使用字形颜色反馈。保留同一按钮 ID、点击区域、禁用和关闭行为，其他图标与 Windows 原生标题栏不变。

字形按 Lucide 实际笔画矩形居中，不再用带空白的文字行高代替。更新页关闭按钮的点击区域中心与更新历史按钮同高。回归覆盖真实字体与多字号的几何位置、五主题三态无底框及对比度、鼠标释放与键盘操作；实际包的五主题截图另行交用户确认，旧包验收保留为历史事实。
