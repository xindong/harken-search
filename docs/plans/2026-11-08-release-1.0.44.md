# Harken Search 1.0.44 发布计划

日期：2026-11-08。卡片：TASK-20261108-RELEASE-1044。功能基线：已验收 QA 提交 85a131a9642140f34498163d0f442b8fd00b146d。

1. 将产品、安装器和发布历史统一更新到 1.0.44；发布日志覆盖相对 1.0.43 的用户可见变化，并保留 Cindy 贡献者。版本准备仅改版本与说明，不改既有功能行为。
2. 在本卡 clone 运行版本、公开合规、扫描、COS/更新专项及正式发布要求的完整测试；从本卡实际代码制作隔离 QA 候选包并核对包、来源提交和运行状态。
3. 通过 PR 将版本准备合入 qa/current，并同步到 main；从 main 的精确提交运行正式构建，回读构建产物与摘要。
4. 使用经核对的公司签名发布入口签署程序和安装包，验证发布者证书、更新签名与产物一致性。签名入口不可用时，保留候选包并停止正式发布。
5. 使用正式发布入口上传不可变的 1.0.44 版本对象；从 COS 实际下载回读安装包、更新包、两套兼容清单、版本索引与更新说明。以未改动的 1.0.43 正式版进行真实下载、替换、重启升级自检，确认版本、签名、摘要和事务收尾。
6. 全部发布检查通过后再切换稳定版指针，回读 GitHub 与 COS 的公开下载和更新入口，并在 Cuevi 记录实际结果。QA 临时产物按 7 天保留。

任何签名、实际分发包或旧版真实升级检查失败，都保持 1.0.43 为正式版，不覆盖已有不可变版本对象。
