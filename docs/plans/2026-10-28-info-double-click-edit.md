# Info 双击编辑与离开保存确认

## 范围

双击元数据信息区进入原有描述、关键词、分类编辑，移除铅笔入口及常驻保存、取消按钮。四个页面图标与封面大小滑条沿用已验收版本。无修改时直接离开；有修改时必须选择“是，保存”或“否，不保存”。关闭按钮和 Escape 不能绕过选择。离开包括切文件、切 Info 页、关闭面板、换库和退出。

## 模块设计

### 编辑状态

InfoEditSession 保存原始字段、编辑状态和待选择状态，可独立测试。修改后恢复原值视为未修改。AppState 保存编辑对象快照、数据库路径、文件 ID 和路径，避免新选择改变保存目标。会话只在界面线程使用，结束即释放草稿。

### 内容与离开动作

FileInfoPanel 标注可双击的元数据区域；双击进入编辑并沿用原字段控件。统一离开检查供页面、文件选择、面板可见性、数据库切换和 Windows 退出调用。切文件时信息区保持原编辑对象直到完成选择；换库和退出暂存后续动作，选择完成后再执行。

更新重启也走同一退出请求：等待用户选择期间继续绘制主循环。托盘退出若主窗口最小化，先恢复窗口以显示保存提示。新建数据库的等待结果与真正失败分开；确认后开始建库，并继续原对话框的进行中和完成状态。

### 保存与失败处理

“是”先校验原库和文件身份，调用原批量元数据事务，仅更新改变的字段。成功后刷新缓存、记录撤销并继续离开；失败保留草稿和错误提示，不继续离开。“否”不写数据库，释放草稿后继续原动作。不修改数据库结构、音频加载或其他编辑入口的功能。

## 验证和交付

- 独立测试覆盖未修改、修改后还原、等待选择、保存失败保留、保存成功、放弃。
- 在本卡独立数据目录生成样本音频和数据库，运行实际包验证双击、文本输入、全部离开场景、Escape 无法跳过，以及文件切换不会改变保存目标。锁定样本数据库验证保存失败；退出后读取样本库确认“否”未写入。
- 同一隔离输入通道分别验证普通退出、最小化后托盘退出和更新重启请求在有草稿时都显示选择，选择前进程不退出；托盘路径同时核对主窗口已恢复。新建数据库弹窗在有草稿时必须先显示保存选择，选“是”后才创建新库，并回读原库确认修改已保存。该场景的触发入口只编入隔离 QA 包。
- 运行相关测试和 Debug 构建，提供本卡实际包与真实截图。旧图标卡的验收不代替本卡用户确认；用户确认前不合入 QA。
