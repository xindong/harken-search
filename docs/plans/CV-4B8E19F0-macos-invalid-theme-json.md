## 本卡行为

- 正常文件：已导出的完整主题，以及包含至少一个已支持颜色字段的旧版部分主题，都应继续加载。
- 失败文件：语法错误、非对象、没有任何受支持颜色字段、受支持字段格式错误时，解析失败且不改调用方传入的颜色；应用启动使用安全回退，不把坏文件标成已加载的自定义主题，也不改写主题文件。
- 未知字段可以与有效颜色字段共存；不能让未知字段单独使导入成功。出错不产生假成功。
