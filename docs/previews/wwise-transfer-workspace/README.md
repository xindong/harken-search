# Wwise 工作台预览（REQ-20261119-WWISE-TRANSFER-WORKSPACE）

可操作的界面原型，对应卡片「开发顺序」第 1 步：先在预览里演示连续拖入、试听切分和目标预览，用户确认后再改产品代码。

## 本地打开

1. 生成示例音效：python tools/gen_samples.py
2. 用浏览器打开 index.html，带上 ?demo=1 会预置一条分段后的脚步和一条金属撞击

示例音效是合成测试音，仅用于演示分段和发送流程。

## 已实现

- 从搜索结果拖入音效，拖入即整条进队列
- 按静音分段（阈值、最短静音、首尾留白可调），或在播放头手动切开、合并相邻段
- 波形定位、片段试听、排除/恢复、改名、撤销
- 目标面板：工程、父级/子级、随机或序列容器、重名不覆盖
- 发送结果逐条列出 Imported / Skipped（模拟，不连接 Wwise）

## 未实现

真实 Wwise 导入、切分持久化、跨会话撤销、产品代码接入。
