# 界面验收

凡是用户能看到或操作的改动，都要用本次改动生成的实际 QA 包验收。设计稿、静态模拟图、旧包截图和自动化契约测试不能单独代替真实界面确认。

## 验收前

- 确认包来自本卡分支，能打开本卡的独立测试数据或实际素材库。
- 确认测试数据、设置、日志和截图放在卡片专用的 QA 目录。
- 写清本次要看的页面、状态、按钮和预期结果。
- 界面测试隔离桌面输入，不占用用户鼠标。

## 验收时

1. 按真实用户操作走一遍，而不是只打开静态页面。
2. 同时检查正常状态、加载状态、失败状态、取消或重试状态。
3. 对涉及数量、索引、保存和数据库状态的页面，操作后核对真实数据是否变化。
4. 截取能看清关键状态的真实窗口图，并记录包路径、数据路径和操作结果。

## 验收结论

- PASS：步骤、画面、数据结果都符合预期。
- FAIL：能复现错误、错误提示不对、数据结果不对或交互中断。
- INCOMPLETE_VERIFICATION：改动涉及界面，但还没有运行对应实际包、截图或用户确认。

AI 可以完成技术验证，但“前端验收通过”必须等用户明确确认截图。用户确认后，才在卡片中记录确认原话和时间。
