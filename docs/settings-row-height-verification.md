# 设置逐项核验012：列表行高

真实测量发现原列表把配置行高又加了一次单元格留白：32px实际36px，100px实际104px，点击区域还额外多出2px。原包、测量及失败检查保存在本卡QA目录。第一轮只改文件名区域仍被波形列撑高；随后统一文件名、波形和封面的内容高度。小字号测试还发现固定数字字体15px会撑高16px行，现将文件名和数字字体一起纳入最小行高，保证绘制、点击和滚动步长一致。

配置值表示包含单元格上下留白的整行高度。实际高度为配置值与必要文字高度两者取大：max(配置值, max(文件名字号, 数字字号)+4px)。例如列表18px、配置16px时，实际为22px；列表24px时至少28px。列表10px时仍需容纳现有15px数字字体，最低19px。没有改变数字字体、字号设置或保存时机；行高仍点击应用后生效。

tools/qa_settings_row_height.py 在私有桌面运行本卡隔离EXE和176个复制音频，读取当前帧真实相邻行的位置及实际点击区域，逐一比较配置、行距和范围。覆盖撤销、放弃、保存失败重试、重启、16/17/20/24/28/30/32/48/64/99/100px、文件名10/18/24px组合、越界输入、滚动至第40行、数据库与文件浏览两种列表、五主题与大小设置窗口。较大组合同时使用24px系统和列表字体，小组合使用18px。

观察字段仅用于隔离测试构建。已有列表字号脚本的可用文字区域断言按此次修复调整：单元格留白由表格添加，不再要求内容区域重复包含留白；仍要求真实字号与文字高度匹配，并另用行距脚本验证整行高度及点击范围。最终结论以本卡实际报告、包身份和原始截图为准。用户确认本项前不合入QA。
