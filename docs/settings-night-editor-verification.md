# 黑夜独立配色编辑（SETCHK-006）

问题：新设置页的黑夜主题行只保留预设选择，既有 night-editor 动作没有用户入口；普通编辑主题动作把时段设为-1，不能代替黑夜独立编辑。实际旧包截图和入口断言已复现缺失。

修改：只在黑夜主题行补回“编辑夜间配色”按钮，复用现有独立编辑器、待应用更改处理和保存流程。编辑器内实时预览无需保存，点击“保存配色”才持久化到黑夜配色文件；取消或关闭放弃当前草稿，返回现有时段配色。白天与手动配色独立保留。白天编辑入口由另一张卡负责，本卡不增加。

验证脚本 tools/qa_settings_night_editor.py 使用指定的隔离EXE、配置和176个复制音频，通过程序自己的输入队列操作真实取色器十六进制输入、实时预览开关、保存、取消和标题关闭；没有调用 draft_color 修改草稿。以控件运行状态、保存文件精确RGBA及真实主界面截图像素共同核验结果；使用应用测试时钟覆盖午夜及08:00/16:00边界，最后恢复真实应用时间。

参数为 --exe、--isolation-root、--output，输出目录不得存在；测试配置应已准备两套合法配色和真实素材库，手动主题使用本卡基线经典深色。禁止使用日常配置。进程身份校验失败只关闭自身持有句柄，不向共享通道发退出命令。

18/24px与1120×800/880×600四组合针对设置页入口实测实际窗口尺寸与可见范围；编辑器是另开的720×760窗口，保存取消控件可用。这不是把编辑器缩成880×600的验证，也不代表编辑器文字会随设置字号放大。

新增编辑器观察信息只在 AURA_BUILD_DIAGNOSTICS && ARIS_PREVIEW_ISOLATION 构建中编译，只读返回已渲染控件、取色器和窗口边界，不执行编辑动作。
