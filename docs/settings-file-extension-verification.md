# 设置013：文件名显示后缀

本项检查现有开关与真实列表绘制的连接，不改变开关行为。勾选、撤销和保存均操作实际设置控件；选择后点击“应用更改”生效，无需重启。

`tools/qa_settings_file_extension.py` 在私有桌面启动独立包，核对进程、EXE 和隔离数据目录，再读取实际文件名绘制位置记录的原名与显示文字。观测字段只编入 `ARIS_PREVIEW_ISOLATION` 包，不通过测试接口直接改设置。

覆盖数据库及文件浏览器的显示/隐藏、中文、多点号、大写后缀、WAV/FLAC/OGG/MP3，文件夹的点号保留；撤销、关闭放弃、保存失败重试与正常进程重启；隐藏时的实际搜索和切换前后结果顺序；五主题、系统和列表18/24px、1120×800及880×600设置窗口。逐文件比对磁盘路径和SHA256，确保不重命名或改写音频。排序检查限于切换前后当前结果顺序一致，不声称覆盖其他排序功能。

测试素材包含176个复制音频和6个复制/转换音频。六条直接准备的记录最初沿用了旧 `search_data`，造成中文搜索失败；保留该轮失败报告，删除隔离库这六条记录并通过软件实际扫描重新入库后，重新完整检查。此过程只准备测试素材，不将扫描功能算成本项验收，也不修改产品搜索逻辑。
